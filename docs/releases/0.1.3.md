# Frontend Quality Toolkit 0.1.3

## Summary

This release synchronizes the root project, Chrome extension and workspace package versions at `0.1.3`, and establishes a documented release process.

## Changes

- Shortened the Chrome Web Store description to 131 characters, within its 132-character limit.
- Added release governance and a repeatable release checklist.
- Added a versioned release note and linked it from the README.

## Compatibility

- Chrome 116 or newer.
- No runtime dependencies or extension permissions changed.
